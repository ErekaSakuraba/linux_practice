# DAY22：画像加工処理の統合と保存処理の共通化

## 学習目的
DAY21で学習した画像加工処理を1つのプログラムにまとめ、複数の加工画像を生成・保存する。また、辞書とfor文を使用して保存処理を共通化する。

## 実施内容
- リサイズ画像の生成
- 切り抜き画像の生成
- 回転画像の生成
- 左右・上下・上下左右反転画像の生成
- 複合加工画像の生成（切り抜き、リサイズ、回転）
- `cv2.imwrite()` の戻り値を使用した保存成否の判定
- 辞書（dict）にファイル名と画像データをまとめる
- `dict.items()` とfor文を使用した保存処理の共通化

## 使用した主な関数・処理
| 関数・処理 | 内容 |
|---|---|
| `cv2.resize()` | 画像のサイズを変更する |
| スライス | 画像の一部を切り抜く |
| `cv2.rotate()` | 画像を回転する |
| `cv2.flip()` | 画像を反転する |
| `cv2.imwrite()` | 画像を保存し、保存成否を返す |
| `os.path.join()` | 出力先パスを作成する |
| `dict` | ファイル名と画像データを対応付けて管理する |
| `dict.items()` | キーと値をペアで取り出す |
| `for` | 各画像に対して保存処理を繰り返す |

## 出力画像
以下の7種類の画像を `output/` フォルダに保存する。

- `output_resize.jpg`
- `output_crop.jpg`
- `output_rotate_90.jpg`
- `output_flip_horizontal.jpg`
- `output_flip_vertical.jpg`
- `output_flip_both.jpg`
- `output_combined.jpg`

## 保存処理の共通化
加工済み画像を辞書にまとめ、for文でファイル名と画像データを1組ずつ取り出して保存する。画像ごとに保存処理を重複して記述せず、画像を追加する場合は辞書に項目を追加することで対応できる構成にした。

## 学習成果
複数の画像加工処理を1つのプログラムに統合し、辞書とfor文を使用して同じ保存処理を共通化する方法を学習した。
