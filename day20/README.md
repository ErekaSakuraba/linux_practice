
# DAY20：画像のピクセル操作・画像加工

## 学習目的

OpenCVとNumPyを使用して画像のピクセル情報を取得・変更し、
基本的な画像加工処理を理解する。

## 学習内容

### 1. ピクセル操作
- 画像の座標を指定してピクセル情報を取得
- 指定したピクセルの色を変更
- 画像の範囲を指定して色を変更

### 2. BGRチャンネル操作
- B（青）、G（緑）、R（赤）の各チャンネルを理解
- チャンネルごとの値を変更
- 特定のチャンネルを除去した際の色の変化を確認

### 3. 明るさの変更
- cv2.add()による明るさの変更
- cv2.subtract()による明るさの変更
- 値が0～255の範囲に収まる仕組みを確認

### 4. グレースケール変換
- カラー画像をグレースケール画像に変換
- チャンネル数の変化を確認

### 5. 色反転
- 画素値を255から減算することで色を反転

### 6. 二値化
- グレースケール画像を閾値によって白黒に変換
- 閾値を変更した際の画像の変化を確認
- 最大値を変更した際の出力値の変化を確認

## 使用ライブラリ

- OpenCV（cv2）
- NumPy

## 成果物

- ピクセル変更画像
- 範囲変更画像
- BGRチャンネル変更画像
- 明るさ変更画像
- 色反転画像
- グレースケール画像
- 二値化画像
