## 学習目的
OpenCVを使用した輪郭検出の基本を理解し、検出した輪郭の面積による選別や外接矩形の取得・描画を実施する。また、輪郭の数や面積、矩形のサイズを数値で確認する。

## 学習内容
- 二値化画像を用いた輪郭検出
- 輪郭数の取得
- 輪郭面積の計算
- 面積による輪郭の選別
- 最大面積の輪郭の取得
- 外接矩形（Bounding Box）の取得・描画
- 輪郭の面積・幅・高さの取得

## 実施した処理

### 1. 二値化
- グレースケール変換後、閾値150で二値化を実施。
- 白い領域と黒い領域に分けた画像を輪郭検出に使用。

### 2. 輪郭検出
- `cv2.findContours()`を使用して輪郭を取得。
- `cv2.RETR_EXTERNAL`を指定し、外側の輪郭を取得。
- `cv2.CHAIN_APPROX_SIMPLE`を指定し、輪郭の点を効率的に保存。
- 検出した輪郭数を確認。

### 3. 輪郭の描画
- `cv2.drawContours()`を使用して検出した輪郭を画像上に描画。
- すべての輪郭を描画し、細かな領域や模様も輪郭として検出されることを確認。

### 4. 輪郭面積の取得
- `cv2.contourArea()`を使用して輪郭ごとの面積を計算。
- `np.argmax()`を使用して最大面積の輪郭のインデックスを取得。
- 最大輪郭の面積を確認。

### 5. 面積による輪郭の選別
- 輪郭の面積を基準に描画対象を選別。
- 面積の閾値を1000、5000、10000に変更し、描画結果を比較。
- 閾値を大きくすることで、小さな輪郭が除外され、大きな領域の輪郭が残りやすくなることを確認。

### 6. 外接矩形（Bounding Box）
- `cv2.boundingRect()`を使用して輪郭を囲む矩形の座標・幅・高さを取得。
- `cv2.rectangle()`を使用して外接矩形を描画。
- 面積が一定以上の輪郭を対象に、矩形を描画する処理を実施。

### 7. 数値による確認
- 輪郭面積、外接矩形の幅・高さを出力。
- 輪郭の形状に基づく面積と、外接矩形のサイズが異なることを確認。

## 検証内容
- 二値化画像から輪郭が取得される仕組み。
- `RETR_EXTERNAL`による外側輪郭の取得。
- 輪郭数と画像内の白い領域・模様との関係。
- 面積による輪郭選別と閾値変更による結果の変化。
- 最大面積の輪郭の取得。
- 外接矩形による位置・サイズの可視化。
- 輪郭面積と外接矩形の幅・高さの違い。
