# DAY21：画像加工の基本操作

## 学習目的
OpenCVを使用して画像のサイズ変更、切り抜き、回転、反転などの基本的な画像加工を行い、加工結果を画像ファイルとして保存する。

## 実施内容
- `cv2.resize()` を使用した画像のリサイズ
- スライスを使用した画像の切り抜き
- `cv2.rotate()` を使用した画像の回転
- `cv2.flip()` を使用した画像の左右・上下・上下左右反転
- 複数の加工処理を組み合わせた画像の生成
- `output/` フォルダへの加工画像の保存

## 使用した主な関数・処理
| 関数・処理 | 内容 |
|---|---|
| `cv2.resize()` | 画像のサイズを変更する |
| スライス (`image[y1:y2, x1:x2]`) | 画像の一部を切り抜く |
| `cv2.rotate()` | 画像を回転する |
| `cv2.flip()` | 画像を反転する |
| `cv2.imwrite()` | 画像をファイルに保存する |
| `os.makedirs()` | 出力フォルダが存在しない場合に作成する |
| `os.path.join()` | フォルダとファイル名を結合する |

## 加工内容
- リサイズ：指定した幅・高さに変更
- 切り抜き：指定した座標範囲を抽出
- 回転：90度回転などを実施
- 反転：左右、上下、上下左右の各方向に反転
- 複合加工：切り抜き、リサイズ、回転を組み合わせて実施

## 出力
加工した画像は `output/` フォルダに保存する。

## 学習成果
OpenCVで画像の形状や範囲を指定して基本的な加工を行い、各加工の結果を保存・確認する方法を学習した。
